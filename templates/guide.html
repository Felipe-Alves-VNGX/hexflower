🌸 Hex Flower Engine Guide

Welcome to the Hex Flower Engine! This module allows you to run procedural hex-crawls using the "Hex Flower" mechanic. With this tool, you can create complex, dynamic environments where navigation is determined by probability and rules rather than static maps.

🚀 Quick Start

Follow these steps to get your first flower blooming:

  1. Create a Flower

    Run the Open Hex Manager macro, or go to Game Settings → Module Settings → Hex Flower Manager. Click "Create" to start a new flower.

  2. Add Hexes

    In the Visual Editor, use the "Add Hex" button to expand your grid. Click on any hex to select it and edit its properties in the right-hand panel:

    • Title & Description: What the players see/encounter.
    • Icon/Emoji: A visual representation on the grid.
    • Type/Biome: Useful for categorizing regions.
  3. Set Rules

    Switch to the Rules tab in the editor. Here you defined how the party moves:

    • Navigation Rules (2d6): Define which roll totals correspond to which direction (N, NE, SE, S, SW, NW, Stay).
    • Edge Behavior: Decide what happens when the party moves off the grid (Stop, Wrap, Reflect, Rotate).
  4. Play!

    Select a Token on the scene (representing the party). Run the Open Hex Navigator macro. You can now roll for navigation or manually click hexes to travel.

🧭 Navigator Controls

The Navigator is your main interface during play.

  • Roll Navigation: Rolls 2d6 (displayed with Dice So Nice if installed) and automatically moves the party token to the next hex based on your rules.
  • Click to Move: Clicking a hex in the navigator creates a "Teleport" dialog, allowing you to manually move the party there (useful for starting positions or GM overrides).
  • Hex Details: Click any hex to view its full description and details in the side panel.

Edge Behaviors

When the party attempts to move off the edge of the defined grid, the Edge Behavior setting determines the outcome:

  • Stop: The movement is blocked. The party stays in the current hex.
  • Wrap (Antipodal): The party warps to the opposite side of the map (useful for planet-like or cylinder worlds).
  • Reflect: The party "bounces" back. If they tried to go North, they are sent South instead.
  • Rotate (CW/CCW): The position is rotated 60° around the center of the map. This creates a "twisted" connection effect.

⌨️ Macros

We have added sample macros to your Macro Directory:

  • Open Hex Navigator: Opens the play window. Accessible to players if they have permission.
  • Open Hex Manager: Opens the editor. GM Only.
